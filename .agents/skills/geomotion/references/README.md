# GeoMotion knowledge index

This directory is the skill's technical knowledge base. It is not a second agent persona or a place for copied chat history. Read the page matching the task; numeric production values live in [defaults.json](../defaults.json).

| Reference | Owns |
|---|---|
| [style.md](style.md) | Appearance, type roles and placement semantics |
| [retention.md](retention.md) | Fast-paced voice/visual rhythm, hooks and readable information beats |
| [composition.md](composition.md) | Camera timing, geographic layer behavior and continuity |
| [scene-format.md](scene-format.md) | Actual scene JSON schema and renderer projection behavior |
| [assets.md](assets.md) | Asset families, atlas contracts and source metadata |
| [tts.md](tts.md) | Pinned speech model, access, quotas and audio reuse |
| [quality.md](quality.md) | Mixing, editable subtitle correctness and verification |
| [delivery.md](delivery.md) | Production stages, compact exports and reusable Sites player |
| [capabilities.md](capabilities.md) | Fitur yang sudah diimplementasikan dan batasnya |
| [troubleshooting.md](troubleshooting.md) | Diagnosis from observed session/data/output state |

[production-defaults.md](production-defaults.md) is a compatibility index for older instructions, not a second preset.

Project-specific facts, sources, coordinates, narration, dates, generated audio and raw media belong with that production, not in this knowledge base. Keep notes reusable and distinguish implemented features from desired asset categories. Repository structure and actual capabilities are documented in [repository architecture](https://github.com/doobieduboo/geomotion/blob/main/docs/architecture.md) and [capabilities](capabilities.md).
